# ELEC5305 Project – Speech and Music Classification

## Project Overview

Develop an audio classification system that can distinguish between speech and music recordings.

The project will use MATLAB to analyse audio signals and extract features.

These features will then be used with a simple classification method to determine whether an audio sample is speech or music.

## Proposed Method

The project will follow these main steps:

1. Collect speech and music audio samples.
2. Prepare the audio files so they use a consistent format and sampling rate.
3. Extract useful audio features using MATLAB.
4. Use the extracted features to train a classifier.
5. Test the system using unseen audio samples.
6. Evaluate the results using classification accuracy and a confusion matrix.

## Tools

- MATLAB
- Signal Processing Toolbox
- Audio Toolbox, if required

## Expected Outcome

The expected outcome is a working MATLAB program that can classify an audio recording as either speech or music.

The project will also investigate which audio features are most useful for distinguishing between the two types of audio.
